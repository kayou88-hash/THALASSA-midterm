# 가상의 게임 THALASSA 사전 예약 페이지 시뮬레이션

## 사용자와 목표
    -사용자 : 게임 테스트에 참여할 예비 플레이어
    -목표 : 게임 소개 및 사전예약 참여 유도
    -주요기능 : 캐릭터 소개, 캐릭터 선점, 테스트 피드백, 사전예약 신청

## 사용자의 흐름
    1. 선점하기: 지역 → 캐릭터 → 이름 입력 → 중복 확인 → 선점 완료
    2. 중복된 이름: 사용 불가 메시지 표시
    3. 사용 가능한 이름: 다음 단계 진행
    4. 선점 완료: 선택 정보 표시 및 내역 확인
    5. 선점 취소: 상태 초기화 후 재선점 가능

## 테스트 결과
    -정상적인 캐릭터 선점 완료
    -이름 중복 및 미입력 안내 확인
    -선점 내역 확인 및 취소
    -모바일 화면에서 정상 작동 확인

## 7주차 결과물에 캐릭터 선점 및 캐릭터명 중복 확인 기능을 추가
    -관리자,운영자,THALASSA 제외 캐릭터명 작성 유도
